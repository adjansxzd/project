# MovieHub - Movie Rating and Review Platform
MovieHub is a modern full-stack movie rating platform where users can discover films, submit ratings, and share opinions.
The main goal of this project is to create a simple and interactive system where users can browse movies, see their average ratings, and leave their own reviews after logging in.
